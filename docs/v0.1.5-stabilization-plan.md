# v0.1.5 Stability Hardening Plan

## Goal

Reduce silent MCP/backend contract drift and make long-running stdio sessions safer without
changing authentication or transport semantics.

## Scope and acceptance criteria

1. **Backend contract drift gate**
   - Keep a machine-readable manifest of every REST operation used by MCP tools.
   - Validate an OpenAPI document against required paths, methods, request fields, and capability
     response fields.
   - Run the validator against a checked-in fixture in pull-request CI.
   - Provide a scheduled workflow that checks the live OpenAPI URL when the repository variable
     `JIPHYEONJEON_OPENAPI_URL` is configured. The hosted service currently returns 404 for the
     conventional `/openapi.json` locations, so activation is explicitly configuration-gated.
   - Until that endpoint is exposed, nightly checks out upstream `PaperReview` and extracts the
     same route/model contract with Python AST, without importing the side-effectful backend app.

2. **Strict MCP inputs**
   - Every tool schema advertises `additionalProperties: false`.
   - Unknown/legacy arguments fail validation instead of being silently discarded.

3. **Safe blog draft lifecycle**
   - Add a read-only preflight tool for GEO/citability checks.
   - Paper-review creation and content updates fail before an HTTP mutation when preflight has
     warnings, unless the caller uses an explicit override.
   - Add partial draft update support through `PUT /api/blog/posts/{post_id}`.

4. **Long-lived runtime efficiency**
   - Reuse one authenticated `httpx.AsyncClient` for the MCP server lifespan.
   - Preserve short-lived clients for direct unit/in-memory tool invocation.
   - Close the shared connection pool during server shutdown.

5. **Non-blocking advisory update check**
   - Capability negotiation remains the only network operation gating tool registration.
   - The GitHub release check runs as a background lifespan task and never delays MCP readiness.

6. **Nightly live verification**
   - Exercise the stdio handshake and safe read calls with a dedicated token.
   - Reject unknown tool arguments in the live protocol path.
   - Run write cleanup only when `JIPHYEONJEON_LIVE_WRITE_TESTS=1`; never leave test bookmarks.

## Verification

- Targeted regression tests for the six acceptance areas.
- `ruff check`, `ruff format --check`, strict `mypy`, unit tests, stdio smoke test, and package build.
- Documentation, skill instructions, version metadata, and distribution metadata agree on the
  resulting tool count and behavior.

## Out of scope

- OAuth/PAT authentication, remote HTTP MCP transport, new backend capabilities, and production
  secret provisioning.
